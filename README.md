# TypeScript Task Manager

A focused task-management interface built to practise strongly typed React component design and predictable state updates.

## Highlights

- Adds tasks with titles and descriptions through an animated form
- Supports completion toggling and task deletion with immutable state updates
- Uses typed component props and a shared task model
- Displays contextual empty-state and workload feedback

## Tech Stack

React 19, TypeScript, Vite, CSS3, and ESLint.
